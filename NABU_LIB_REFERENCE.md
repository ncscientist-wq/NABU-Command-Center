# NABU-LIB reference and attribution

NABU-LIB is an upstream NABU development library created by DJ Sures.

- Upstream project: <https://github.com/DJSures/NABU-LIB>
- Reference revision documented during NABU Command Center engineering: `c9cfc6b93290ca77cfa223367810729863cf3c9e`
- Credit: DJ Sures and the NABU-LIB project

The upstream README at that documented revision states that the project has no conventional license and requests credit. No conventional redistribution license was found during the NABU Command Center publication audit.

For that reason, NABU-LIB source is **not included or redistributed** in this publication repository. This record preserves attribution and identifies the exact upstream source without inventing permissions or license terms.

The production NABU Command Center v1.0 client uses the separately installed z88dk `+nabu` runtime and headers.
